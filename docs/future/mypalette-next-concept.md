# MyPalette v2 - Concept Notes

> 본 문서는 현재 v1을 구현하면서 떠오른 아이디어를 정리한 문서이다.
> 아직 확정된 기능이 아니며, 구현 전 사용자 경험(UX)과 서비스 방향성을 기록하기 위한 메모이다.

---

# Why?

현재 MyPalette는 사용자가 직접 색을 만들고
5개의 카테고리에 분류하여 기록하는 서비스이다.

구현을 진행하면서 이런 생각이 들었다.

'사람은 카테고리로 기억되지 않는다.'

결국 모든 색은 Pieces of Me에서 하나의 그림이 된다.

그렇다면 처음부터 하나의 Palette 안에 모든 색을 모으는 것이
서비스 철학과 더 잘 맞지 않을까?

---

# New Vision

MyPalette는

'나를 색으로 기록하는 서비스'

에서

'나를 색으로 기록하고,
그 기록들이 하나의 그림이 되어가는
감성적인 퍼스널 아카이브'

로 발전한다.

사용자는 글보다
색과 그림을 통해
'나'를 바라보게 된다.

---

# Core Philosophy

사람은 하나의 단어로 설명되지 않는다.

작은 특징,
좋아하는 것,
가치관,
관심사,
이상향이

하나씩 색이 되어 쌓이고

시간이 지나며 서로 스며들어

세상에 하나뿐인 그림을 만든다.

# Watercolor

사용자가 색을 추가하면

랜덤 위치에

수채화 물감 한 방울이 떨어진다.

물감은

다른 색과 조금씩 겹친다.

색은 서로 스며들며

새로운 분위기를 만든다.

사용자는

내가 그림을 그리고 있는 것이 아니라

내 삶이 하나의 그림이 되어가는 경험을 한다.

---

# v2 Goal

MyPalette는

'나를 색으로 기록하는 서비스'

를 넘어

'나를 하나의 그림으로 기록하는 서비스'

기록을 남기는 것이 아니라
